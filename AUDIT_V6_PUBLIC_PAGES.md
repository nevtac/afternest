# AfterNest public-page v6 audit

Quick implementation audit for homepage-adjacent public routes.

- Homepage: v6 hierarchy now leads with what AfterNest is, what it does, and clear patient/volunteer/hospital pathways.
- Volunteer: needs the same typography scale, more immediate role expectations, and a more polished mobile application flow.
- Program: core story is strong but visual hierarchy should match the homepage and keep service examples readable on smaller screens.
- Hospitals: content is credible but needs tighter hero scale, clearer ownership visuals, and improved mobile table/card behavior.
- Mobile: reduce desktop-scale headlines, preserve 16px+ body text, make CTAs full width, stack cards intentionally, and avoid oversized photo treatment.

The shared `assets/public-v6.css` layer implements these changes without changing referral, workspace, privacy, or pilot-data behavior.
