# AfterNest nonprofit refinement release

This release shifts the public experience away from a software-company presentation and toward a real nonprofit / hospital-support organization.

Key changes:
- Concise five-section homepage centered on the discharge-to-home gap.
- Volunteer recruitment promoted to the primary public action.
- New service-first navigation and nonprofit footer.
- New AfterNest house-and-nest identity mark and favicon.
- Global typography, spacing, card, button, form, dashboard, and mobile readability audit.
- New professional palette based on deep navy, evergreen teal, sage, warm sand, and white.
- Simplified Program, Volunteer, Hospital Partner, and Team/Governance pages.
- Operations demo retains functionality while adopting the new brand.
- Existing intake, resources, training, impact, patient plan, printable briefs, and roadmap remain available.

The project remains a presentation prototype. No hospital relationship, 501(c)(3) status, or clinical outcome is claimed.
