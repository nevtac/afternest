# UI / UX audit summary

Reference patterns reviewed from current hospital and nonprofit sites:
- Hospital homepages prioritize one clear task or need at a time, use large readable type, restrained color, and simple audience pathways.
- Nonprofit homepages lead with the human problem and mission, then make volunteering / supporting the mission highly visible.
- AfterNest now follows those patterns instead of presenting the public site like a software product.

Sizing decisions:
- Display H1 capped at 66px desktop, 50px mobile.
- H2 capped at 46px desktop.
- Body copy standardized around 16-17px.
- Buttons use a 44px minimum target.
- Public page sections reduced to roughly 58-76px vertical spacing.
- Dashboard and form density reduced without making labels illegible.

Color decisions:
- Deep navy for trust and governance.
- Evergreen teal for primary actions and service continuity.
- Sage for supportive backgrounds.
- Warm sand for human-story accents.
- White / cream for readability.
- Violet-heavy software gradients removed from the public experience.
